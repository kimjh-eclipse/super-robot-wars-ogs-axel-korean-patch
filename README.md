# Super Robot Wars OGs — 액셀 알마 역할 교체 패치

PS2 **슈퍼로봇대전 OG ORIGINAL GENERATIONS**의 라미아 로렐리스 루트를 **액셀 알마**로 플레이하는 개조 패치입니다.

**OGs 한글패치 v1.4.3s1** 위에 얹어 쓰는 패치입니다. 한국어 번역 패치가 아니라 **역할 교체 개조 패치**입니다.

📖 **문서 사이트**: https://kimjh-eclipse.github.io/super-robot-wars-ogs-axel-korean-patch/

- 현재 버전: **v20261024**
- 빠른패처에서 **숨겨진 요소 자동 습득 (OG2)**을 선택할 수 있습니다(기본값 꺼짐). 기존 대사·밸런스·음성 변경은 항상 유지됩니다.
- 배포 패키지: [릴리즈 페이지](https://github.com/kimjh-eclipse/super-robot-wars-ogs-axel-korean-patch/releases/latest)에서 `SRWOGS_AxelRoleSwap_kr_v20261024.zip`을 내려받으세요 (빠른패처 + xdelta 동봉)
- 패치 파일만 필요하면: [`patch/SRWOGS_AxelRoleSwap_kr_v20261024.xdelta`](patch/SRWOGS_AxelRoleSwap_kr_v20261024.xdelta)

> **v20261024**: 소울게인·바이사가 무장별 전투 대사·음성을 넣고, 적 라미아·안쥬르그 능력치를
> 원래 적이던 액셀·소울게인 기준으로 올렸습니다. 「머스터쉬 맨」 호칭과 액셀·라미아·레몬·W16 관계 대사도 정리했습니다.
> **v20261002·v20260904·v20260831 적용본**은 빠른패처가 자동 인식해 차이만 덧씌웁니다.

> **이 저장소에는 게임 ISO가 포함되어 있지 않습니다.** 패치와 작업 스크립트만 배포합니다.

## 적용 방법

### 방법 1 — 빠른패처 (권장)

릴리즈 ZIP을 풀고 `patcher\OGS_AxelSwap_QuickPatch.exe`를 실행해 ISO를
선택한 뒤 [패치 적용]을 누르면 됩니다. 기준 ISO(v1.4.3s1)와 v20261002·v20260904·v20260831 적용본을
모두 인식합니다. ISO를 제자리에서 수정하며, 적용 전 원본 구간을 `.ogsbak`
백업으로 남기고 적용 전후 해시를 검증합니다. [백업으로 되돌리기]로 백업 시점
상태로 복원할 수 있습니다.

### 방법 2 — xdelta

1. OGs 한글패치 **v1.4.3s1**이 적용된 ISO를 준비합니다. (xdelta는 기준 ISO 전용)
2. xdelta UI 등으로 `patch/SRWOGS_AxelRoleSwap_kr_v20261024.xdelta`를 적용합니다.

명령줄로 적용하는 경우:

```bash
xdelta -d -s srwogs-v1.4.3s1.iso SRWOGS_AxelRoleSwap_kr_v20261024.xdelta srwogs-axel.iso
```

> 일본판 원본 ISO에는 적용되지 않습니다. 한글패치를 먼저 적용해 주세요.

## 바뀌는 것

### 인물
라미아 로렐리스 자리에 **액셀 알마**가, 액셀이 있던 적 자리에 **라미아**가 들어갑니다.
한쪽만 바꾼 것이 아니라 양방향 교환입니다. 파일럿 데이터 · 초상화 · 상태창 · 이름 표기가 함께 바뀝니다.

### 기체
- 아군 슬롯 → **소울게인**
- 적 슬롯 → **안쥬르그**

적 보스의 HP는 원래 값(18,928)을 유지합니다. 기체만 바꾸고 난이도는 건드리지 않았습니다.

### 이벤트 대사
대상 3,245건을 전수 대조해 **2,722 오프셋**을 교체하고, 이후 33차에 걸친
추가 교정으로 **고유 대사 슬롯 1,036개**를 다시 손봤습니다.
이름과 조사뿐 아니라 **상대가 부르는 호칭과 말투**(라미아의 존댓말 → 액셀의 반말)까지 맞췄습니다.

### 시나리오 · 인물 관계
액셀의 성격은 **A PORTABLE의 기억상실 액셀**과 **OG2 액셀 패치 ver.1.20**을
기준으로 재구성했습니다.

- 초반의 유연한 농담과 기억 회복 후의 군인적 말투
- 레몬과의 연인 관계 (설득 · 석방 · 재회 · 최종전 흐름 반영)
- 쿄스케와는 단순한 숙적이 아닌, 서로가 폭주하거나 변절할 때 막아주기로 한
  상호 견제의 전우형 라이벌
- 라미아의 「액셀 대장」 호칭과 대장 · 부하 관계 복원
- 액셀을 W시리즈 · 인형 · 피조물로 취급하던 역할 교체 잔재를 제거하고,
  자신의 선택으로 싸우는 인간 장교로 정리
- 라미아 화자 대사 786건의 말투 · 호칭을 전수 교정

### 전투 대사 · 음성
**슈퍼로봇대전 A PORTABLE 한국어판**에서 액셀의 대사와 음성을 이식했습니다(클립 181종).
레몬 · 빈델 전용 대사가 관계없는 적에게 재생되던 문제(45건)와
「운이 없군, 당신…!」의 비정상적인 중복 재생을 교정했습니다.
ATRAC3+ → PS2 ADPCM 재인코딩 후 OGs 음성 뱅크에 재패킹했습니다.

무기명이 나오는 대사는 실제로 그 무기를 쏠 때만 나오도록 맞췄고,
게임 중반의 기체 선택(소울게인改 · 바이사가 · 아슈세이버 · 라즈앙그리프)에 대응하는
전용 대사 슬롯 **98개**를 복원했습니다.
