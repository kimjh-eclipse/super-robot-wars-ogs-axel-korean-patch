## 적용 방법

1. ZIP을 폴더째 풉니다.
2. `patcher/OGS_AxelSwap_QuickPatch.exe`에서 ISO를 선택합니다.
3. 원하는 옵션을 체크하고 [패치 적용]을 누릅니다. **다섯 옵션의 기본값은 모두 꺼짐**입니다.
