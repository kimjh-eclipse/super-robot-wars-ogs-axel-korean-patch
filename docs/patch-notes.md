# v20261026 패치노트

빠른패처의 기존 오우카 옵션을 **「오우카 생존 + 젠가 밸런스」 묶음 옵션**으로 확장했습니다. **「숨겨진 요소 자동 습득 (OG2)」**은 별도로 유지합니다. 두 옵션의 기본값은 모두 꺼짐입니다.

- **묶음 ON:** OG2 44화 오우카 생존·라피에사쥬 잔류, 다이젠가 HP 8800·장갑 2100, 환장 없이 무장 8개, 무장 개조 10단계 총비용 165,000(공격력 증가 2,500)을 적용합니다.
- **묶음 OFF:** 오우카의 원래 결말과 다이젠가의 원래 HP·장갑·무장 구성·무장 수치·개조비용으로 복원합니다. 이전 공개판의 다이젠가 강화도 옵션에 포함됩니다. 기존 슬레이드겔미르 갈아타기 호환성은 유지합니다.
- 통합 후 내장 무장 세 개에서 참함도 연출이 나오던 오류를 수정했습니다. 게임의 실제 연출 선택 함수에서 이전 분리형과 동일한 자원이 선택되는 것을 확인했습니다.
- 원래 참함도 다섯 무장과 내장 무장 세 개의 공격력·EN·기력을 재조정했습니다. 제너럴 블라스터는 EN 20의 ALL이며 ALLW는 아닙니다.

이전 버전의 역할 교체·전투 대사·음성·적 라미아 조정, 추가 기체와 6화 보상, 다른 기체의 변경사항은 공통으로 유지됩니다. 숨겨진 요소 자동 습득은 원래 획득 시점에 지급하며 지난 화로 소급하지 않습니다.

오우카 생존은 **44화 결말 이전의 메모리카드 세이브**에서 진행해야 합니다. 옵션을 해제해도 메모리카드에 이미 저장한 합류·보유 기록을 삭제하지 않습니다. 다이젠가 기체·무장 수치는 새 ISO를 부팅하면 선택한 설정을 따릅니다. **에뮬레이터를 완전히 재시작하고 게임 내 세이브로 불러오세요.** 이전 세이브 스테이트는 구 코드를 복원합니다.

기준 한글판 v1.4.3s1, v20260831·v20260904·v20261002·v20261024·v20261025·v20261025.1의 공개 옵션 조합에서 업데이트할 수 있습니다. ZIP의 patcher/OGS_AxelSwap_QuickPatch.exe에서 두 옵션을 선택한 뒤 적용하세요. xdelta는 기준 한글판 전용이며 두 옵션이 모두 꺼진 결과입니다.

게임 코드로 네 조합의 무장 수치·실제 연출 연결과 오우카 장면·합류 명령을 검사했습니다. 실제 44화 전체 연출과 모든 전투의 실플레이 검증을 완료했다는 뜻은 아닙니다.

설치 방법과 결과 해시는 [소개](home.md)를 참고하세요.
