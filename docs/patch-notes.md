# v20261102.1 업데이트

## OGs 액셀 역할 교체 패치 완결판 — v20261102.1

이번 버전으로 기능 추가를 마무리합니다. 그동안 제보와 테스트에 참여해 주신 분들께 감사드립니다.

### 이번 변경

- OG1 기체 다섯 종류를 OG2의 대응 기체 입수 이벤트에 함께 지급합니다. 파일럿 없이 기체만 지급하며 중복 생성하지 않습니다.
- OG2 수리장치·보급장치 지급을 각각 1개에서 2개로 늘렸습니다.
- 무기 개조비용을 재조정하고 전 등급에 20% 할인을 적용했습니다. 10단계 총비용은 0·1등급 88,000 / 2등급 105,600 / 3·4등급 176,000입니다. 15단계까지 단계별 비용에 적용합니다.
- 리바레 무장 비용 등급을 로슈 블레이드 0 / 건슬레이브 1 / 아키시온 버스터 2로 설정했습니다. 세 무장 공격력 상승 등급은 모두 0을 유지합니다.
- 모든 무기의 공격력 상승량은 유지했습니다. 3·4등급의 공격력 상승량도 변경하지 않았습니다.
- ‘적 강화’ 옵션의 적 기체·무기 기본 개조 보정을 +1에서 +2단계로 변경했습니다. 파일럿 6개 능력치 +5, 기본 HP 20,000 미만 적의 HP +10%, 기존 개조 상한은 유지합니다. 적이 새로 생성될 때 적용합니다.
- v20261102의 잉그램·R-GUN 리바레 합류, 발시온 개 추가, 11화 보상·대사·로딩 수정과 기존 누적 변경사항을 포함합니다.

# v20261102 업데이트

## 이번 업데이트

### 잉그램·R-GUN 리바레 합류

- OG2 11화에서 다른 차원의 잉그램이 R-GUN 리바레와 함께 등장합니다. 원래 세계에서 일찍 기억을 되찾아 아군과 싸웠지만, 최종결전 중 차원 이동으로 이 세계에 표류했다는 설정입니다.
- 모의전이 끝난 뒤 기지 습격 장면에서 등장하며, 전투 후 정식 합류합니다. 11화 시작 직후 실행되는 이벤트는 아닙니다.
- 리바레: HP 8,300, EN 500, 장갑 2,100, 운동성 120, 이동력 7. 잉그램 기본 격투 146·사격 151.
- 로슈 블레이드 3,900 / 건슬레이브 4,100·탄수 15 / 아키시온 버스터 4,900. 원래 무장 연출을 유지합니다.
- 무장 공격력 개조 상승 등급은 콜드 메탈 나이프와 같습니다. 비용은 앞의 두 무장 최저 등급, 아키시온 버스터는 한 단계 위입니다.
- 잉그램의 직격을 집중(SP 15·Lv16)으로 변경했습니다. 다른 정신기와 트윈 예측은 유지합니다.

### 30화 발시온 개 추가

- OG1에서 회수한 기체를 개수했다는 정비진의 대사를 추가하고, OG2 30화 종료 후 발시온 개를 기체만 지급합니다.
- HP 9,000, EN 300, 장갑 2,100, 운동성 120, 이동력 6. 범용 탑승을 지원합니다.
- 무장 공격력: 디바인 암 3,900 / 크로스 스매셔 5,000 / 에너지 드레인 2,700 / 채프 그레네이드 3,100. 사거리·소모량·연출은 원형을 유지합니다.
- 기존 OG1 기체와 적 기체의 데이터는 변경하지 않습니다.

### 11화 보상·대사 교정

- 11화 종료 후 G 임팩트 스테이크·네오 차크람 슈터·스텔스 부메랑·고성능 레이더·메가 제너레이터를 각각 1개 추가 지급합니다.
- 11화 격납고에서 안쥬르그의 날개·스커트를 묘사하던 대사를 소울게인의 콧수염을 소재로 교정했습니다.

- 무기 개조비용: 최저 비용 등급을 제외하고 20% 인하. 콜드 메탈 나이프처럼 가장 저렴한 등급은 유지합니다. HP·EN·장갑 등 기체 개조비용과 무기 개조 시 공격력 상승량은 바꾸지 않았습니다.

## 선택 옵션 — 다섯 가지, 기본값은 모두 꺼짐

빠른 패처에서 원하는 항목을 각각 선택할 수 있습니다.

1. 숨겨진 요소 자동 습득 (OG2)

원래 받는 시점에 격추수·레벨·숙련도·난이도·회차 조건 없이 숨겨진 보상을 받습니다.

- 22화: 그라비톤 런처. 클리어 시 인스펙터 보상 5종(시시오 블레이드, G 임팩트 스테이크, 강철의 혼, 용자의 증표, 고성능 전자두뇌). 같은 화의 원래 보상과 중복 지급하지 않습니다.
- 23화 클리어: 부스트 해머
- 24화 클리어: 시시오 블레이드
- 34화: 빌트빌거 타입L 출격, 클리어 후 보유
- 35화: 길리엄의 스텔스 부메랑
- 39화: 카라의 스텔스 부메랑, 라즈앙그리프 레이븐, 란드그리즈 레이븐
- 40화 클리어: 강철의 혼, 용자의 증표
- 42화 루트 선택: G 임팩트 스테이크, 네오 차크람 슈터
- 휴케바인 Mk-Ⅲ 타입R·게슈펜스트 Mk-Ⅱ 타입S: 원래 루트별 합류 시점(42화 루트 선택 또는 반대 루트의 44화 클리어 후)

이미 지나간 화의 보상은 소급 지급하지 않습니다. 소울게인·바이사가·아슈세이버의 획득 처리는 이 옵션과 별개입니다.

2. 오우카 생존 + 젠가 밸런스

오우카 생존과 다이젠가 강화를 묶은 옵션입니다.

- 44화에서 라투니의 설득, 쿠엘보의 기억 회복, 아기라를 쓰러뜨리는 흐름은 유지하면서 오우카가 생환하도록 바꿨습니다.
- 어느 44화 루트를 진행해도 클리어 후 오우카와 라피에사쥬가 합류하도록 보완했습니다.
- 이후 사망을 전제로 한 대사도 생존 흐름에 맞춰 교정했습니다. 공통 45화의 대사 8개는 생환해 치료받고 있는 내용으로 바꿨습니다.
- 44화 종료 이전의 게임 내 세이브부터 적용됩니다. 이미 45화로 넘어간 저장에 소급 합류시키는 기능은 아닙니다.

다이젠가
- HP 7,800 → 8,800, 장갑 1,900 → 2,100
- 환장 없이 내장 무장 3개와 참함도 무장 5개를 함께 사용
- 내장 무장에서 참함도 연출이 나오던 오류 수정
- 무장 개조 10단계 공격력 증가량 총 2,500. 전용 개조비용 조정에 공통 20% 인하도 적용됩니다.
- 참함도 계열 5개 무장에 배리어 관통. 내장 무장 3개는 제외

무개조 기준 최종 무장입니다. P는 이동 후 공격 가능, ALL은 전체 공격입니다.
- 다이너믹 너클: 공격력 4,000 / 사거리 1~4 / P / EN 0 / 기력 제한 없음
- 전광석화: 공격력 4,100 / 사거리 1~4 / 이동 후 불가 / EN 5 / 기력 제한 없음
- 대차륜: 공격력 4,400 / 사거리 2~3 / P / EN 15 / 기력 제한 없음
- 제너럴 블라스터: 공격력 5,200 / 사거리 3~6 / 이동 후 불가 / EN 20 / 기력 110 / ALL
- 가디언 소드: 공격력 5,000 / 사거리 1~2 / P / EN 20 / 기력 110
- 뇌광베기: 공격력 5,700 / 사거리 1~3 / P / EN 30 / 기력 120
- 운요의 태도: 공격력 6,300 / 사거리 1~2 / P / EN 50 / 기력 130
- 용권참함도: 기존 합체기 공격력 계산 방식 / 사거리 1~3 / P / EN 65 / 기력 130

제너럴 블라스터는 ALL이며 ALLW는 아닙니다. 옵션을 끄면 다이젠가의 HP·장갑·무장 구성·수치·개조비용은 원래 상태로 돌아갑니다. 공통 무기 개조비용 인하와 다른 기체의 기본 변경은 유지합니다.

3. 자금 +20% · PP 2배

적 격추 보상을 늘립니다. 기존 보너스와 분배 계산을 거친 보상에 적용하며, 시나리오 이벤트로 지급하는 자금·PP는 유지합니다.

4. 적 강화

- 적 파일럿의 격투·사격·기량·방어·명중·회피를 각각 5 올립니다. SP·레벨·격추수는 유지합니다.
- 적 기체·무기의 기본 개조를 1단계 높입니다. 난이도별 차이와 원래 개조 상한은 유지합니다.
- 기본 HP가 20,000 미만인 적의 기본 HP를 10% 올립니다. 20,000 이상인 적과 아군·중립 기체는 제외하며 개조·난이도로 추가되는 HP는 유지합니다.
- 적 파일럿 보정은 적 소속일 때, 기본 개조 보정은 적이 새로 생성될 때 적용됩니다.

5. 액셀·제오라 정신기 변경

- 액셀: 불굴 → 철벽(SP 20), 트윈 예측 → 혼(SP 50), 각성 SP 50
- 제오라: 저격 → 번뜩임(SP 10), 철벽 → 가속(SP 10)
- 습득 레벨과 그 외 정신기는 유지합니다.
