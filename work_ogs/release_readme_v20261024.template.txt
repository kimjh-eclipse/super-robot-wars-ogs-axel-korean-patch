슈퍼로봇대전 OGs 액셀 역할 교체 패치 v20261026
========================================================

이클립스입니다. OGs 한글패치 v1.4.3s1 위에 적용하는 역할 교체 패치입니다.

■ 빠른패처 사용

ZIP을 폴더째 풀고 patcher\OGS_AxelSwap_QuickPatch.exe를 실행하세요.
ISO를 선택하고 원하는 옵션을 체크한 뒤 [패치 적용]을 누릅니다.

1. 숨겨진 요소 자동 습득 (OG2)
2. 오우카 생존 + 젠가 밸런스

두 옵션의 기본값은 모두 꺼짐이며 각각 선택할 수 있습니다.
기존 오우카 체크박스가 오우카·젠가 묶음 체크박스로 확장됐습니다.

■ 오우카·젠가 묶음 옵션

ON: 오우카 생존·라피에사쥬 잔류와 다이젠가 강화·통합 무장을 함께 적용합니다.
OFF: 오우카 원래 결말, 다이젠가 원래 HP·장갑·무장·개조비용으로 복원합니다.
기존 공개판에 항상 적용되던 다이젠가 강화도 이제 이 옵션으로 선택합니다.

ON 상태의 다이젠가: HP 8800 / 장갑 2100 / 환장 없이 무장 8개
무장 개조 10단계 총비용 165000 / 공격력 증가 2500

통합 후 내장 무장 세 개에서 참함도 연출이 나오던 연결 오류도 수정했습니다.
실제 연출 선택 함수로 원래 분리형과 같은 자원이 선택되는지 검증했습니다.

오우카 생존은 OG2 44화 결말 이전의 게임 내 세이브에서 진행해야 합니다.
이미 지난 화에 소급 합류시키지 않습니다. 옵션을 꺼도 메모리카드에 저장된
합류·기체·보유품을 삭제하지 않습니다. 다이젠가 수치는 선택한 ISO를 따릅니다.
기존 슬레이드겔미르 갈아타기를 위한 탑승 호환성은 옵션과 관계없이 유지합니다.

■ 숨겨진 요소 자동 습득

이전 옵션을 유지합니다. 체크하면 OG2의 숨겨진 무기·기체·강화파츠를
원래 획득 시점에 조건 없이 받습니다. 이미 지난 화의 보상은 소급하지 않습니다.
역할 교체·전투 대사·음성·적 라미아 조정, 추가 기체·6화 보상과 다른 기체의
기존 변경사항은 공통으로 유지됩니다.

■ 적용 대상과 백업

기준 한글판 v1.4.3s1과 공개 v20260831 / v20260904 / v20261002 /
v20261024 / v20261025 / v20261025.1의 모든 공개 옵션 조합을 지원합니다.
ISO 크기: 4,518,150,144 바이트
기준 SHA256: 9D39F5EA9E560E864A9FC4B0ABC234FD42619D846FC1A9C2A98CBA19CF5D5A0C

변경 전 ISO 구간을 <ISO 파일명>.ogsbak으로 백업합니다.
[백업으로 되돌리기]는 직전 작업 전 상태로 복원합니다. 다음 변경 작업에서
백업도 갱신됩니다. patcher 폴더의 파일들은 모두 함께 두세요.

■ xdelta

기준 한글판 v1.4.3s1 전용이며, 두 옵션이 모두 꺼진 결과입니다.
옵션을 쓰려면 빠른패처를 사용하세요.

xdelta.exe -d -s "srwogs-v1.4.3s1.iso" "SRWOGS_AxelRoleSwap_kr_v20261026.xdelta" "출력.iso"

■ 결과 ISO SHA256
기본(둘 다 OFF): __ISO_SHA__
숨겨진 요소만 ON: __HIDDEN_SHA__
오우카·젠가 묶음만 ON: __OUKA_SHA__
둘 다 ON: __BOTH_SHA__
기본 결과 MD5: __ISO_MD5__
패처 EXE SHA256: __EXE_SHA__
전체 파일 체크섬은 SHA256SUMS.txt에 있습니다.

■ 실행 시 주의

PCSX2를 완전히 종료했다가 다시 실행하고 게임 내 메모리카드 세이브를
불러오세요. 이전 세이브 스테이트는 구 데이터와 코드를 통째로 복원합니다.
일본판 원본에는 적용되지 않습니다. 한글패치 v1.4.3s1을 먼저 적용하세요.

게임 코드·옵션 조합·패처 적용·복원 검증을 수행합니다.
실제 44화 전체 연출과 모든 전투의 실플레이 확인은 아직 완료하지 않았습니다.
게임 ISO와 세이브는 배포물에 포함하지 않습니다.
