슈퍼로봇대전 OGs 액셀 역할 교체 패치 v20261024
========================================================

OGs의 라미아 아군 루트에 액셀 알마를 배치하고, 라미아를 원래 액셀의
적 역할로 이동시킨 시나리오·기체·전투 대사·음성 통합 패치입니다.

■ v20261024에서 바뀐 것

- 소울게인 무장별 전투 대사·음성 추가
  청룡린·현무강탄·백호교·무주작·기린의 준비·타격 대사를
  무장마다 따로 재생합니다. (A PORTABLE 액셀 음성)
- 바이사가 무장별 전투 대사·음성 추가
  열화인·수류조아·지참질공도·풍인섬·광인섬. 초반·후반 말투를 구분합니다.
- 적 라미아·안쥬르그 능력치 상향
  적으로 나오던 소울게인·액셀에 맞춰 운동성과 무장 공격력·명중 보정,
  라미아의 격투·사격·명중·회피를 올렸습니다.
- 대사 교정
  · 「머스터쉬 맨」 호칭을 OG2 액셀 패치 ver.1.20과 같은 「발키리」로 정리
  · 액셀이 스스로를 기계처럼 말하던 표현 수정
  · 액셀(대장)·라미아(대원) 사이 존칭, 레몬·액셀의 연인 말투 정리
  · W16·W17은 동급 라이벌, W16에게 액셀은 대장으로 관계 정리

■ 필요한 것

다음 중 하나의 ISO가 있으면 됩니다.

1. 한국어화 v1.4.3s1 기준 ISO (srwogs-v1.4.3s1.iso)
   크기: 4,518,150,144 바이트
   SHA-256: 9D39F5EA9E560E864A9FC4B0ABC234FD42619D846FC1A9C2A98CBA19CF5D5A0C

2. 이전 버전 패치가 적용된 ISO (v20261002, v20260904, v20260831)
   → 빠른패처가 자동으로 인식해 차이만 덧씌웁니다.

다른 ISO에는 적용하지 마세요. 패처가 해시를 확인해 위에 없는 ISO는
수정하지 않습니다.

■ 적용 방법 1 — 빠른패처 (권장)

1. ZIP을 폴더째 풉니다.
2. patcher\OGS_AxelSwap_QuickPatch.exe를 실행합니다.
3. [찾기]에서 ISO를 선택합니다. (기준본이든 이전 버전 적용본이든 무방)
4. [패치 적용]을 누릅니다.

ISO를 제자리에서 직접 수정하며, 적용 전 원본 구간을
<ISO 파일명>.ogsbak 백업으로 남깁니다. [백업으로 되돌리기]를 누르면
백업 시점 상태로 복원됩니다. [상태 확인]으로 현재 ISO 상태를
검사할 수 있습니다.

■ 백신이 패처를 막을 때

패처는 코드 서명이 없어 Windows Defender가 오탐하는 경우가 있습니다.
파일 자체에는 문제가 없습니다. 아래 중 하나를 쓰세요.

1. 아래 SHA-256으로 진본을 확인한 뒤 예외 처리하세요.
   명령 프롬프트에서
     certutil -hashfile "OGS_AxelSwap_QuickPatch.exe" SHA256

   OGS_AxelSwap_QuickPatch.exe
     __EXE_SHA__
   OGS_ISO_ranges.bin
     __BIN_SHA__
   OGS_ISO_ranges_upgrade_v20260831.bin
     __UP0831_SHA__
   OGS_ISO_ranges_upgrade_v20260904.bin
     __UP0904_SHA__
   OGS_ISO_ranges_upgrade_v20261002.bin
     __UP1002_SHA__

2. Windows 보안 > 바이러스 및 위협 방지 > 보호 기록 > [디바이스에서 허용]

3. 아래 「적용 방법 2」의 xdelta 방식을 쓰세요.

■ 적용 방법 2 — xdelta (빠른패처를 못 쓸 때)

xdelta는 기준 ISO(v1.4.3s1)에만 적용됩니다.

xdelta\xdeltaUI.exe 실행 → Apply Patch 탭
  Patch      : xdelta\SRWOGS_AxelRoleSwap_kr_v20261024.xdelta
  Source File: 기준 ISO (srwogs-v1.4.3s1.iso)
  Output File: 새로 만들 패치 ISO
명령줄이라면
  xdelta.exe -d -s "srwogs-v1.4.3s1.iso" "SRWOGS_AxelRoleSwap_kr_v20261024.xdelta" "출력.iso"

※ 원본을 그대로 두고 새 ISO를 만들며 디스크 여유가 약 4.3GB 필요합니다.

■ patcher 폴더의 파일을 분리하지 마세요

OGS_AxelSwap_QuickPatch.exe는 같은 폴더의 OGS_ISO_ranges.bin과
OGS_ISO_ranges_upgrade_*.bin을 읽습니다. exe만 따로 옮기면 패치할 수 없습니다.

■ 적용 결과

완성 ISO SHA-256:
__ISO_SHA__
완성 ISO MD5:
__ISO_MD5__

■ 주요 수정 내역 (누적)

- 라미아·액셀 양방향 파일럿·기체·시나리오 역할 교체
- A Portable 액셀 한국어 전투 대사·음성 이식
- OG2 액셀 패치 ver.1.20 장면·관계 반영
- 액셀·레몬 연인 관계, 액셀·쿄스케 상호 견제·전우형 라이벌 관계 복원
- 라미아의 「액셀 대장」·보고체·상관 호칭 복원
- 35화 이후 강화형 소울게인·아슈세이버 지급, 액셀 갈아타기
- 전투 대사 발동 조건 복원, 관계 전용 대사 오발동·중복 교정
- 소울게인·바이사가 무장별 전투 대사·음성
- 적 라미아·안쥬르그 능력치 조정

■ 주의

- 이전 ISO에서 만든 에뮬레이터 세이브 스테이트는 사용하지 마세요.
  스테이트는 이전 ISO의 데이터와 실행 코드를 통째로 복원하므로 수정이
  반영되지 않습니다. 에뮬레이터를 완전히 재시작한 뒤 게임 내 저장
  데이터(메모리카드)를 불러와 플레이해 주세요.
- 원본·기준 ISO 파일 자체는 배포물에 포함되어 있지 않습니다.
